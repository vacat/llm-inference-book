# 《大模型推理技术详解》

> **从原理到工程实践 -- 基于 ds4 (DwarfStar) 源码的逐行解读**

## 关于本书

这是一本面向普通技术人员的大模型推理技术教程，以 antirez/ds4（DeepSeek V4 推理引擎）的源码为蓝本，用通俗易懂的语言讲解大模型推理的完整技术栈。

### 特点

- **结合 ds4 源码讲解**：每个概念都标注了 `文件名:行号`，可直接跳转到源码
- **由浅入深**：从"什么是推理"到"张量并行"，6 个部分 26 章逐步推进
- **逐行解读关键代码**：Embedding、RMSNorm、RoPE、Attention、MoE 等核心算子逐行拆解
- **动手实验**：每章末尾有实践练习，在真实环境中验证理解
- **全中文**：语言简单通俗，不堆砌公式

### 读者要求

- 有基本的编程经验（任何语言）
- 不需要机器学习背景
- 最好有 macOS + Apple Silicon 环境（用于实践）

### 全书结构

| 部分 | 章节 | 主题 |
|------|------|------|
| 第一部分 基础篇 | 第 1-3 章 | 推理概念、环境搭建、推理全貌 |

## 如何开始

1. 从 `SUMMARY.md` 查看完整目录
2. 按顺序从第 1 章开始阅读
3. 每章末尾的"动手实验"建议实际操作
4. 遇到不理解的概念，查阅附录 C 术语表

## 配套源码

本书基于 ds4 仓库：https://github.com/antirez/ds4

```bash
git clone https://github.com/antirez/ds4.git
cd ds4
make
./ds4 --inspect
```
